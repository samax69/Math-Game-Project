Welcome to the Math-Game-Project! This is a fun and fast-paced Android math game designed to test your calculation skills.

About the Game
In this game, players solve basic math problems to practice quick thinking and improve their math speed. You start the game by picking what kind of math operation you want to practice. You can choose from addition, subtraction, multiplication, or division.

Once you select an operation, the game begins and you have exactly 30 seconds to type in the correct answer for the question. Every time you get a right answer, you earn 10 points. You start the game with 3 lives in total. If you give a wrong answer, you will lose one life. When you lose all your lives and they reach zero, the game ends. You will then be taken straight to a result page to see your final score.

Technology Used
This app was built using modern Android development tools. The entire user interface is created majorly using Jetpack Compose, which makes the screens look great and run smoothly. I also used NavController to handle the movement between different screens, like going from the home menu to the game screen, and finally to the result page.

How to Play
To play the game, just open the app on your Android device and click on the math operation you want to practice. Read the question and type your answer as quickly as you can before the time runs out. Try to get as many right answers as possible to get a high score before losing your three lives!
